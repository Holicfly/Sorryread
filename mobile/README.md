# 素若阅读 · Android

Flutter Android 客户端与根目录 WPF 客户端独立构建。用户功能、互联方法和截图见[项目 README](../README.md)。Android 对外版本号由 `android/app/build.gradle.kts` 定义，`pubspec.yaml` 保留开发版本和递增构建号。下文记录各阶段的实现与验证。

开发前阅读 [跨端约定](../docs/CROSS_PLATFORM_DEVELOPMENT.md)、[技术方案](../docs/FLUTTER_TECHNICAL_PLAN.md)。本阶段的步骤、范围和验证记录见 [同步实施记录](../docs/DEVICE_SYNC_IMPLEMENTATION.md)，数据协议见 [Sync v1](../shared/contracts/device-sync-v1.md)。

## 使用

1. 两端接入可互通的局域网，打开新版电脑应用。
2. 电脑打开“设置 → 设备互联 → 二维码展示”。
3. 手机从书架或我的进入“与电脑同步”，点击“连接新设备”，允许相机权限并扫码。
4. 在电脑上确认连接，手机安全保存配对身份并自动双向对账。之后打开应用会自动连接；电脑复用保存的端口，IP／端口变化时手机通过 mDNS 的地址列表重新发现。前台失败重试间隔最多 30 秒。
5. 可点击“立即同步”和“查看同步记录”。“断开连接”保留配对，仅暂停本次运行；“重新连接”或下次启动恢复。“删除当前连接设备”撤销配对并保留阅读数据，可再连接新设备。电脑二维码窗口也可解除旧配对。

默认同步收藏、最近阅读、所有网页／章节阅读位置和相应移除操作，不传正文、目录文件、封面、设置、书签或笔记。书架展示真实同步元数据，分为收藏与最近阅读；默认隐藏 18mh 和夜社，连续点击“我的书架”五次可双向切换分组，重启默认普通分组。分组只作用于显示，同步仍覆盖全部书籍。默认封面使用六款内置插画与独立书脊阴影，邻近封面不重复。真正并发的阅读位置保留候选，需在同步页或电脑设备窗口选择。

## 发现

底部“发现”默认搜索桌面现有的 12 个普通书源，不包含我的书城网、18mh 和夜社。结果按书源横向切换，各自保留列表、分页和滚动位置；只展示书名及可获取的作者，没有“全部”或排序入口。接近底部自动翻页，失败可单独重试此书源；每次最多并发 4 个请求。连续点击顶部“发现”五次切换到 18mh 搜索与夜社入口，再点五次切回；重启恢复普通模式，与书架分组的切换相互独立。

18mh 输入关键词搜索；夜社按钮打开小说列表，也可缓存书名和链接到本机后按书名搜索，不调用网站的关键词搜索。输入小说详情或章节 HTTPS 网址仍可直接解析。两种结果都只显示书名，滚动接近底部自动请求下一页；失败可重试。点击进入已有阅读器，成功加载后记录最近阅读，收藏需手动操作；章节网址从指定章节开始，普通结果入口优先续读。

夜社的“缓存全部书目”支持后台进度通知、暂停与断点继续，说明按钮列出首次资源与时间估算。下载过程中即可搜索已缓存的部分，结果明确标注覆盖范围；完成后可手动更新书目。数据库仅保存本地书名与链接，不下载正文或封面、不参与同步。系统强制结束任务后可回到页面继续。步骤和验证范围见 [0.2.5 开合动画与夜社书目](../docs/MOBILE_V025_COVER_YESHE.md)。

普通／18mh／夜社分别保存最多 50 条本地记录，支持单条删除和清空，不参与设备同步；夜社已有网址记录在结果页“最近解析”中展开查看。实施和验证范围见 [发现页实施记录](../docs/MOBILE_DISCOVER_IMPLEMENTATION.md)。

夜社书目缓存采用最多 4 路并发和有界预取，按连续页序原子入库；兼容旧版断点。临时错误会重试，站点限流时自动降速并遵守等待时间，暂停时取消全部请求。界面按当前实际速度估算剩余时间；不在 APK 中预置书目。提速对比和全量验证见 [0.2.6 缓存提速记录](../docs/MOBILE_V026_YESHE_SPEED.md)。

## 阅读

正文取消顶部额外留白，进入阅读时允许延伸到刘海／摄像头区域，退出后恢复窗口设置。底部正文渐隐，电量／章节名／时间保持清晰；默认信息栏高度 16 dp，至少向上预留 12 dp，并叠加系统底部安全区；Android 12 以上再参考屏幕圆角半径提高间距，大字体时相应增高。滚动使用渐变遮罩；分页仅对下一页预览渐隐，本页文字完整保留。呼出菜单后，顶部“添加到书架／已在书架”可切换收藏状态。Android 启动图标使用用户指定的透明 PNG。步骤与验证见 [阅读全屏与菜单调整](../docs/READER_FULLSCREEN_POLISH.md)。

点书架封面进入全屏阅读；长按保留收藏／移出最近阅读操作。正文由手机独立获取并解析为段落，已缓存章节可以离线阅读。点中央显示上下工具栏，支持目录、前后章、章节内进度、夜间和底部设置。默认左右点按仿真翻页；连续滚动模式中，任意点按切换工具栏，不触发翻页。阅读底部显示本机电量、时间、当前章节名及页数／章节数。目录跟随阅读配色，当前章节使用书签图标、字重和“正在读”文字强调。

设置支持阅读窗口亮度、暖色护眼、字号、字体、六种纯色和仿真／上下滑动／无动画。默认系统字体；宋体（思源宋体）、黑体（Noto Sans CJK SC）、楷体（霞鹜臻楷）、思源黑体和霞鹜文楷全部内嵌，离线直接选用，已移除方正字体。字体保持原始文件与许可，来源和 SHA-256 见 assets/fonts/manifest.json。封面百分比按整本书的章节数折算；旧进度缺少总章数时显示“待读取”，首次打开书籍后补全。阅读设置仅在本机保存，退出恢复窗口亮度和系统栏。缓存正文最多 150 章／40 MiB，滚动保留邻近章节窗口；不改变同步协议和桌面数据库。

规则包括现有桌面书源目录 14 项与手机端夜社 1 项；网络书源可用性取决于站点，动态源按需启用 WebView。尚未逐一完成所有站点的在线验证，规则失效时显示错误并支持重试。实施步骤与验证范围见 [阅读页实施记录](../docs/MOBILE_READER_IMPLEMENTATION.md)。

前台自动对账；Android 后台任务按系统条件约十五分钟起调度，恢复前台补齐。电脑需保持运行；系统终止应用后不保证实时同步。连接受网络隔离、VPN 路由和 Windows 防火墙影响，请按系统提示允许该程序在可信私有网络访问，不必关闭防火墙或对公网映射端口。

## 收藏与阅读统计

收藏和最近阅读点击封面时，从当前书架位置放大并掀开封面，退出时反向合上；沿用被点击的封面与标题，保留原列表位置。动画仅用于书架入口，搜索结果不增加封面；系统关闭动画时直接切换。

长按书籍先触发触感反馈，再打开操作菜单；收藏页可以置顶／取消置顶，多本置顶时最后置顶的在前，并显示图钉标记。普通与特殊分组分别排序，置顶仅在本机保存。

“我的”展示每日一句和真实阅读统计。每日一句按本地日期缓存，联网失败保留上次内容。时长仅累计正文加载成功后、阅读界面处于前台的时间，普通与特殊书源均计入，后台和加载等待不计入。书籍按书名与作者去重，作者缺失时与已知同名书兼容。每天累计实际阅读严格超过 2 分钟才计作阅读日；今天尚未达标时，连续天数从昨天开始计算。旧记录仅导入已读书籍数，旧时长和阅读天数从本次更新后开始。置顶、统计、每日一句均不参与设备同步。

本次修复与验证见 [0.2.4 实施记录](../docs/MOBILE_V024_SEARCH_STATS.md)。

## 工具链与构建

Flutter **3.47.7 stable**、Dart **3.13.5**，Android 最低 API 26。依赖由 pubspec.lock 锁定；SDK/JDK 在仓库外，禁止提交 local.properties、配对信息或签名私钥。Windows 下 Pub 缓存和工程位于不同盘时，已关闭不兼容的 Kotlin 增量路径缓存。

在 mobile/ 执行：

```powershell
flutter pub get
dart format --output=none --set-exit-if-changed lib test integration_test test_driver
flutter analyze
flutter test
flutter build apk --debug
flutter build apk --release --target-platform android-arm64
```

产物为 build/app/outputs/flutter-apk/app-debug.apk、app-release.apk。Release 当前沿用开发签名，仅供本地验收；正式分发需配置正式签名。不要把测试目标 APK 当作应用交付，测试后重新构建 lib/main.dart。

## 测试

Debug 使用独立包名 com.sorryread.sorryread_mobile.dev，Release 仍为 com.sorryread.sorryread_mobile。测试脚本的 PackageName 参数默认指向 .dev。测试目标仅安装到开发包，避免覆盖正式应用的数据。flutter drive 默认在结束后卸载目标应用，验收命令显式使用 --keep-app-running；清理时只卸载本次创建的 .dev 测试包。

```powershell
flutter test integration_test/app_smoke_test.dart -d <设备ID>
flutter drive --keep-app-running --driver=test_driver/screenshots.dart --target=integration_test/app_smoke_test.dart --dart-define=CAPTURE_SCREENSHOTS=true -d <设备ID>
```

默认真机检查：三项导航、空书架、同步布局、原生摄像头启动、私有 SQLite 重开、安全存储读写和原生发现启动／停止。出现系统相机询问时在手机上允许。测试使用独立数据库和安全存储键，不导入用户业务数据。截图写到仓库 artifacts/device-sync-phone/。

显式设置 RUN_LIVE_SYNC=true 可测试真实 HTTPS、同步书籍、断开／启动恢复／删除配对；需要隔离 C# 测试服务端和新鲜二维码数据。test/sync_live_test.dart 通过 SORRYREAD_SYNC_TICKET 环境变量读取隔离服务票据，可在 Windows 验证跨语言冲突闭环。integration_test/lan_probe_test.dart 使用实际局域网地址，不允许回环地址，专门用于区分 USB 转发与无线网络联调。详细启动方式见实施记录。

扫码入口启动成功、图片解码、实际拿手机扫描屏幕是不同证据，测试报告分别记录。

## 代码入口

| 位置 | 职责 |
| --- | --- |
| lib/app/ | 启动、依赖注入、路由、三项导航 |
| lib/design_system/ | 亮暗主题、颜色角色、卡片 |
| lib/data/ | Drift／SQLite、原子事务、完整状态、待发送操作、日志 |
| lib/sync_engine/ | JSON 契约、因果合并、证书固定、双向同步 |
| lib/core/ | 原生局域网发现、Android 后台任务 |
| lib/features/bookshelf/ | 实际书架和收藏／最近阅读操作 |
| lib/features/discover/ | 普通书源搜索、搜索历史、18mh 搜索、夜社列表与网址解析 |
| lib/features/profile/ | 每日一句、阅读统计及其余设置占位 |
| lib/features/sync/ | 状态控制器、扫码、同步页、记录与冲突 |
| lib/features/reader/ | 目录／正文解析、缓存、排版、阅读位置和阅读 UI |
| test/、integration_test/ | 共享契约、布局、持久化和真机检查 |

Widget 不直接执行 SQL 或网络同步；生产数据库通过后台连接打开。手机配对凭据由系统安全存储保护，Android 禁止应用数据备份。
