素若阅读使用说明
适用版本：1.1.9

更新内容
- 新增“设置 → 设备互联”：手机扫描电脑二维码并在电脑确认后，同步收藏、最近阅读和全部阅读进度；仅在两端可互通的局域网内工作。
- 新增“我的书城网”入口：进入小说搜索后单击按钮选择，输入书籍 id 或链接直接阅读；章节分页链接自动定位到该章。
- 我的书城网使用独立历史记录，显示书名并可点击重新打开。
- 后续目录页加载失败时保留已加载章节，并标注目录未完整加载。

一、从哪里开始

- 想看一段章节正文：回到主页，选择“网址解析”，粘贴完整章节网址，点击“开始解析”。
- 想找一本小说：在主页选择“小说搜索”，输入书名、作者或关键词，点击“开始搜索”。
- 想继续上次阅读：打开“书库”，点击最近阅读或收藏中的书籍。
- 想快速重新搜索：点击右下角“搜索”，在中央输入框输入内容并按 Enter。
- 想查看这份说明：打开“帮助 → 使用说明”，点击弹窗底部的“阅读详细说明”。

二、主页与界面切换

【回到主页】
点击右下角“主页”，或选择“解析 → 返回主页”，回到网址解析和小说搜索的输入界面。

【返回前一界面】
右下角“返回”用于回到可返回的前一界面，例如从正文返回搜索结果。没有可返回目标时，按钮会置灰。

【右下角箭头】
- 阅读正文时：上一章、下一章。
- 搜索结果页：上一页、下一页。
- 主页或书库：不可用。
- 没有前后章节或页码时，对应箭头会置灰。

【窗口大小】
可拖动窗口边缘调整大小。切换主页、搜索、阅读等界面不会主动改变窗口尺寸。

三、网址解析

1. 在主页点击“网址解析”。
2. 粘贴完整章节网址，点击“开始解析”，或在输入框按 Enter。
3. 解析成功后进入正文；遇到提示时，按照底部状态栏说明操作。
4. 手动解析的页面不一定带有章节目录。没有目录时，不能通过目录跳章，也不会显示透明模式的 F1 章节位置提示。
5. 想再次读取当前页面，可使用“解析 → 重新解析”。
6. 想寻找以前解析过的页面，可打开“历史记录”。

四、小说搜索与搜索模式

【开始搜索】
1. 在主页点击“小说搜索”。
2. 输入书名、作者或关键词，点击“开始搜索”，或按 Enter。
3. 默认是聚合搜索，会同时显示多个书源的搜索结果；当前聚合搜索包含 12 个 HTTP 书源。
4. 在结果页顶部点击书源名称，查看该书源找到的小说；点击小说标题进入阅读。
5. 某个书源没有结果或显示失败时，可以换另一个书源，或更换关键词。
6. 聚合搜索新增“云书斋”书源。某个书源翻到末页后，即使页面仍显示下一页入口，软件也会保留已经加载的结果并停止继续翻页。

【切换搜索模式】
- 在主页单击“小说搜索”按钮，可选择“聚合搜索”或“我的书城网”。
- 双击“小说搜索”按钮，切换为“18mh 小说网单独搜索”；再次双击，切回聚合搜索。
- “我的书城网”不提供关键词搜索，只接受书籍 id 或本站书籍/章节链接，并且只允许 ASCII 字符；粘贴章节链接后会自动定位到对应章节，找不到时从第一章开始。
- 查看按钮提示或底部提示，可以确认当前使用哪种模式。
- 搜索模式只能在主页切换；中央搜索框只沿用当前模式，不会替你切换。

【查看结果与翻页】
- 每页最多显示 20 条结果，使用右下角的前后箭头翻页。
- 第一页不能再向前翻，最后一页不能再向后翻。
- 底部状态栏会显示本次搜索词、进度和结果；较长提示会省略显示。
- 结果页不显示主页的输入行和搜索记录。想搜索其他内容，请点右下角“搜索”；想修改搜索模式，请回主页。

五、中央搜索框

1. 点击右下角“搜索”，或右键托盘图标选择“搜索”，打开中央胶囊形输入框。
2. 输入书名、作者或普通关键词，按 Enter 或点击右侧按钮，按当前聚合 / 18mh 模式搜索；我的书城网模式请输入书籍 id 或本站链接。
3. 聚合 / 18mh 模式输入网址会直接进行解析；我的书城网模式只接受书籍 id 或本站链接，通过书源读取目录和正文。
4. 点击输入框内部可继续输入，不会关闭。
5. 点击外围变暗区域，或按 Esc，取消并关闭输入框；这次点击只关闭遮罩，不会同时点中下面的内容。
6. 每次关闭都会清空输入，包括取消关闭和提交后关闭。下次打开是空白输入框，不保留上次草稿。
7. 阅读中打开搜索框并发起小说搜索，会保留原来的阅读位置，便于返回继续阅读。

六、搜索记录

【查看与重搜】
- 记录显示在主页的小说搜索输入行下方。网址解析模式和搜索结果页不显示记录。
- 聚合搜索、我的书城网与 18mh 的记录分开保存，每种模式最多 15 条。我的书城网记录显示书名，点击后重新打开书籍；同一本书只保留最新记录。
- 点击关键词胶囊，可直接再次搜索。重复搜索同一词，会将它移到最前，不重复增加记录。
- 没有记录时，记录区域和“管理”按钮会隐藏。

【管理与删除】
1. 点击记录区域的“管理”。
2. 点击某条记录右侧的红叉，删除该条。
3. 点击“全部删除”，清空当前模式的记录。
4. 点击“完成”，退出管理。
以上删除操作不再询问确认，请谨慎点击。

【开启与关闭】
- “设置 → 搜索记录 → 开启搜索记录”：继续保存后续关键词，默认开启。
- “设置 → 搜索记录 → 关闭搜索记录”：只停止新增，旧记录仍保留并可使用。
- “设置 → 搜索记录 → 清除搜索记录”：一次清空所有模式的全部记录，不需要再次确认。
- 开关状态和已有记录在重启后保留；网址解析不会写入关键词记录。

七、正文阅读与切章

【滚动正文】
- 使用鼠标滚轮滚动；主窗口还可以拖动右侧滚动条。
- ↑ 或 PageUp：向上整屏滚动。
- ↓ 或 PageDown：向下整屏滚动。
- 在“设置 → 滚动距离”中可以调整方向键每次滚动的行数，范围为 1–100 行。
- 阅读窗口获得焦点时，音量−键向上滚动，音量+键向下滚动；音量+键滚动到底后可进入下一章。离开阅读窗口后，音量键仍按系统原有方式工作。
- 当前章节已经到底后，再按一次 ↓ 或 PageDown，可以进入下一章。
- 无下一章或正在加载时，不会自动切换。

【切换章节】
- 点击右下角上一章 / 下一章箭头。
- 或选择“解析 → 上一章 / 下一章”。
- 或在阅读窗口内按 ← / →。
- 或按 Shift+F / Shift+J，分别进入上一章 / 下一章。
- 透明窗口还支持左右半边双击切章，详见下一节。

章节切换需要对应章节存在，而且当前没有正在解析或加载。方向键和章节快捷键需要阅读窗口获得焦点；目录、菜单获得焦点时，方向键用于对应控件。

【章节目录】
1. 有目录的书籍，可将鼠标移到阅读区左侧边缘，点击出现的目录展开按钮。
2. 点击目录中的章节标题跳转；当前章节会高亮。
3. 再次点击收起按钮，收起目录。
4. 没有目录时，可以通过已有的上下章按钮继续阅读，或返回搜索重新选择书籍。
5. 如果章节数后标有“未完整加载”，表示后续目录页加载失败；已经显示的章节仍可阅读，可稍后重新打开书籍再试。

【复制正文】
选中文字后按 Ctrl+C，或右键选择“复制”。未选中文字时，右键菜单中的复制不可用。

八、透明阅读

1. 正在阅读正文时按 F12，进入透明模式；再次按 F12 返回主窗口。
2. 透明模式保留正文、隐藏窗口背景，适合简洁阅读。先点击透明窗口让它获得焦点，再使用按键。
3. 鼠标滚轮、方向键、Shift+F / Shift+J 仍可使用；滚动到底后再按 ↓ / PageDown 可切下一章。
4. 双击整个窗口左半边，进入上一章；双击右半边，进入下一章。中间没有常显分界线或提示。
5. 单击正文不会切章，可正常聚焦和选择。双击不会触发选词；无对应章节或加载中不会切章。
6. 可拖动透明窗口的空白边缘移动窗口；也可先按 F12 回到主窗口，调整位置和大小后再进入透明阅读。
7. 按住 F1，中央临时显示“当前第 x/y 章：章节标题”；松开、窗口失焦或显示约 2 秒后收起。
8. F1 只在透明窗口聚焦，而且当前章节能在目录中找到时有效。主窗口、没有目录的手动解析页面不显示。
9. 按 Shift+E 或 Alt+M，可以隐藏或恢复透明窗口。隐藏后章节快捷键不会影响其他软件。

九、书库：最近阅读与收藏

【继续阅读】
1. 点击书库图标，或右键托盘选择“书库”。
2. 通过小说搜索进入的书会加入“最近阅读”，最多保留 10 本。
3. 点击书籍卡片，打开上次阅读章节并恢复进度；加载时请稍候，不要连续点击。
4. 手动解析的单篇页面不一定进入书库，可以从“历史记录”中寻找。

【收藏】
- 阅读时点击收藏按钮，将常读书籍加入收藏；再次操作可取消收藏。
- 收藏最多 50 本，可在书库收藏区域找到。
- 收藏已满时，先取消不再需要的收藏，再添加新书。

【删除】
- 将鼠标移到书籍卡片右侧，可看到删除按钮。
- 在“最近阅读”中删除，只移除最近阅读记录；已收藏的书仍留在收藏中。
- 在收藏区域删除，会询问是否取消收藏；取消收藏不会同时清掉仍存在的最近阅读记录。
- 两处都已移除的书，可以重新搜索进入。

- 中央搜索框打开时，输入和方向键用于搜索框，不切换底下的章节。
- 向上滚动到顶后不会自动切上一章。

十一、窗口、托盘与退出

- 点击窗口右上角关闭或最小化，只会隐藏到系统托盘，程序仍在运行。
- 找不到窗口时，双击任务栏右下角的托盘图标，或按 Alt+M / Shift+E。图标可能位于托盘的隐藏图标区域。
- 真正退出请选择“解析 → 退出”，或托盘菜单的“退出程序”。

托盘右键菜单：
1. 显示窗口：恢复隐藏前的阅读窗口。
2. 返回主页：恢复主窗口，回到输入界面。
3. 搜索：恢复主窗口，打开中央输入框并聚焦。
4. 书库：恢复主窗口，打开最近阅读与收藏。
5. 退出程序：保存当前状态并退出。

“返回主页”“搜索”“书库”会先退出透明模式，再进入主窗口。托盘菜单可用上下键选择、Enter 执行、Esc 关闭。

十二、字体、主题、滚动与历史记录

- 在“设置”中调整字体、字号、文字颜色和窗口置顶。
- 在“设置 → 滚动距离”中调整方向键每次滚动的行数，支持 1–100 行。
- 文字颜色选择“跟随主题”，可以随深浅主题调整。
- 选择“文字颜色 → 自定义”后，可点色板、拖动取色区域或输入颜色值；点“确定”应用，点“取消”保留原色。
- “应用主题”可选深色、浅色或跟随系统，托盘菜单也会同步换色。
- “历史记录”用来查找以前解析的页面；小说关键词请查看搜索记录，整本书续读请查看书库。

十三、TXT 导出与个人数据

【导出当前章节】
1. 正在阅读时，选择“解析 → 保存为 TXT”。
2. 本次只保存当前章节，不是整本书。
3. 底部状态栏会提示实际保存路径。
4. 同名章节再次导出会覆盖同名 TXT，重要内容请先另存备份。

TXT 导出位置：
程序所在文件夹\Data\txt

【个人数据目录】
阅读记录、书库、搜索记录和设置所在目录：
程序所在文件夹\Data

导出的 TXT 位于这个目录内的 txt 子文件夹中。
在程序所在文件夹中打开 Data，即可找到这些数据。
如果程序所在文件夹无法写入，则使用 %LOCALAPPDATA%\Sorryread，TXT 保存到其 txt 子文件夹。
升级时，请先退出程序，再运行新版安装器。旧数据由安装器搬到 Data；直接启动程序不会搬迁旧数据。
如果 Data 已有内容，安装器不会覆盖，旧目录也会保留。

【备份与卸载保留】
- 备份前，先从托盘彻底退出程序，再复制整个 Data 文件夹；使用回退目录时，请备份实际使用的 Sorryread 数据目录。
- 数据目录可能包含个人阅读记录和登录信息，不要随意分享。
- 卸载时默认保留数据。出现是否同时删除数据的询问时，选择“否”，可保留记录、收藏、设置和 TXT。
- 选择“是”仅删除此程序所在文件夹内的 Data 和导出 TXT；需要保留时请先备份。
- 旧的 %LOCALAPPDATA%\Sorryread 不随卸载清理。
- 程序旁的“素若阅读使用说明.txt”是本操作说明，不是个人导出的小说正文。

十四、遇到问题时

- 无法切章：先点击阅读窗口，确认它已获得焦点，再检查是否有对应章节、是否仍在加载。
- F1 没有提示：确认正在透明阅读，并且当前书籍有可用目录。
- 某个书源没有结果：切换其他书源，或调整搜索词后重搜。
- 搜索框草稿消失：这是正常行为，关闭即清空。
- 详细说明无法打开：确认程序旁存在“素若阅读使用说明.txt”，并为 TXT 设置默认打开应用，也可直接双击文件。
- 查找详细说明入口：打开“帮助 → 使用说明”，点击底部“阅读详细说明”。
- 查看版本：选择“帮助 → 关于素若阅读”。
