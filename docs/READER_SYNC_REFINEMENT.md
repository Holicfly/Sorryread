## 实现与边界

- 阅读页使用固定的双向滚动基准，前面的内容向上扩展。目录选章、下一章和恢复位置均重置到目标章基准，直接反向滚动可以看到上一章末尾。
- 正文按当前章前 2、后 5 预加载，HTTP 最多 2 个请求，动态书源预加载串行；动态书源前台跳章与预加载也共用导航队列，避免同一 WebView 抓到另一章的 DOM。选章时停止旧的预加载队列，请求按章节去重。
- 下载正文与排版分离；原始缓存最多 8 章，可见排版窗口通常 3 章，保留原点过渡时最多 4 章。复用既有排版，列表使用精确高度，滚动位置通知只更新页脚和工具栏，不重建整页。
- 卷页画布覆盖整个屏幕和留白；正文保留排版边距。时间、电量始终固定在屏幕底部，下一页仍在同位置。顶栏无边框、无阴影，底栏使用 0.5 逻辑像素分隔线。
- 设置颜色从当前纸张配色派生，统一导轨底色、滑块、亮度、护眼开关、字号及字体入口；翻页模式选中项使用 240 ms 滑移动画。没有修改全局应用主题。
- 同步详细记录包含方向、书名、书架收藏／最近阅读／阅读进度、章节及章内百分比，同一轮快速保存的同书同类变化合并显示。主页预览按屏幕和字号控制为 1–4 条，其余进入“更多记录”，两端按滚动 24 小时保留，启动、写入、读取及运行期间清理。
- 自动同步不切换按钮 busy 状态；手动请求与正在执行的自动同步合并为串行后续任务。本地变化静默 2 秒合并触发，持续变化最多等待 8 秒；后台任务占用数据库租约时 5 秒后再试，避免本地待发送变化被通知等待遗漏。
- 协议继续为 v1，通过 hello 的可选 capabilities 声明 watch。新电脑端支持最长 25 秒异步等待，变化即唤醒；手机等待期间不占数据库同步租约，切后台／手动操作／断开／销毁时取消等待。通知等待不写同步日志；旧端／缺少可选接口时回退轮询，空闲 15→30 秒，网络错误按 5／10／20／30 秒退避。原有证书固定、配对凭据、断开与删除设备语义保留。
- 桌面只调整同步服务、日志保留和现有记录列表构建上限；其余阅读、导航、解析流程不做功能改动。日志存储不再用 200 条裁剪，桌面原有详情窗口仍限制构建最近 200 个条目，手机“更多记录”可逐项滚动查看全天记录。

## 验证记录

- Flutter 单元／组件测试：45 项通过，独立 C# HTTPS 联调项默认跳过；本次另行启动隔离的 C# 服务，该项已实际通过，包括双向进度、移除、冲突处理、无空闲日志刷屏、watch 能力、4 秒内接收电脑变化、通知期间手动同步、断开及重连。
- 增加跳章后立即反向滚动、下一章后反向滚动、前 2 后 5 提前请求、24 小时过期物理删除、超过 200 条当天记录保留、手动请求合并和后台租约重试的回归用例。
- C# DeviceSync.Tests：共享契约、持久化、无接收回声、删除、完整位置、快照、HTTPS、异步通知唤醒／超时／取消／配对撤销、日志保留、端口复用和 WPF 退出／重连／明暗主题窗口测试通过。主机没有 ASP.NET Core 8 框架，测试以 DOTNET_ROLL_FORWARD=Major 使用已安装的 .NET 10；交付桌面包为自包含 .NET 8 构建。
- 真机 Profile：120 Hz，合成正文 12 次双向滑动，共 685 帧；构建 P95 2.452 ms、最大 4.511 ms，栅格 P95 0.656 ms、最大 4.353 ms，无构建或栅格阶段超过 8.33 ms 的帧。没有旧版的相同场景基线，不能据此宣称提升百分比，也不能扩展到所有网络和书源。
- 真机交互与截图：整屏卷页、固定页脚、底部设置、昼夜、目录跳转后直接向前阅读、保存恢复、同步预览及更多记录已检查。卷页截图停在动画中点，使用实际画布，未修改图像。位于 artifacts/reader-refinement-phone/；Profile 数据在 artifacts/reader-profile/result.json。
- 首次 Profile 试跑沿用了 Flutter 默认正式包名，已恢复原 arm64 Release 安装包，未清除应用数据；随后增加 .profile 独立包名，性能测试与正式包、.dev 调试包分别隔离。首次试跑驱动回传失败未纳入性能结论，以上数据来自隔离后成功回传的测试。
- 额外桌面 SearchHistory.Tests 回归在“normal: copy and search become available for a selection”处失败；将原始 HEAD 导出到独立临时目录，在相同 .NET 10 环境运行，也在同一断言失败。没有修改该阅读控件或放宽测试，不能把该套回归报告为全通过。两份输出见 artifacts/reader-refinement-desktop-regression.log 与 artifacts/reader-refinement-desktop-baseline.log。
