## 动画

- 只从书架的收藏／最近阅读传入 `BookOpening`。普通、18mh、夜社的搜索结果保留原来的阅读导航。
- 动画沿用被点击的内置封面、标题和进度，从原始书架矩形放大；以左书脊为轴做透视旋转，增加阴影、明暗和封面背面。阅读页在封面后露出；退出使用同一进度反向关闭。
- 书架在阅读期间保留原始列表顺序，避免最近阅读更新导致封面关闭时目标位置跳动。阻止重复点按开多个阅读页；系统关闭动画时跳过过渡。
- 过渡约 760 毫秒，正文加载异步进行，不会为了动画重复抓取章节或提前写入未读位置。封面解码只为本次封面提高精度，未新增图片素材。

## 本地书目与后台下载

- 网站前三页实测每页 30 条，共 25,230 条、841 页。只访问该站 HTTPS 小说分类分页，只保存书名和规范详情链接，不下载封面、正文或章节目录。
- 使用 Android 自带 SQLite 的独立 `yeshe_index.db`，不写原有阅读／同步数据库。主键链接去重；分页书目与下一页检查点在同一事务中提交。单页失败、中断或进程退出后可继续；已缓存条目仍能搜索。
- 原生 `dataSync` 前台服务独立于 Flutter 页面与 Activity，用户启动后可在后台继续。通知展示进度并提供暂停；Android 13 以上首次启动请求通知权限。拒绝通知不阻止系统允许的前台任务，但系统可能只在任务管理界面展示任务。
- 一次一个请求，页间至少 650 毫秒，连接／读取限时，失败最多重试两次并退避；遇到验证码、结构变化、缺失／跳跃分页或非 200 时停止并保留检查点。不跳转到其他网站，不绕过访问限制。
- 按 Android 官方要求声明 `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC` 和服务类型，处理服务超时；不注册开机后台启动，不自动重试永久失败任务。系统强制结束后，回到页面点继续。有限时唤醒锁只用于下载期间，暂停／结束时释放。
- 缓存按钮旁说明列明首次估计 15～30 分钟、流量 5～30 MB、数据库 3～10 MB，均非保证值。界面显示已缓存数量、分页进度、按实测页耗时估算的剩余时间、接收网页字节数及数据库含 WAL 的实际占用。
- 完成后可手动“更新书目”重新扫描，保留旧书目用于搜索，不自动删除网站下架的旧条目。网站在分页期间新增／调整条目可能改变结果顺序，刷新后可补齐。
- 搜索框输入普通文字查询本机书名，空格分词同时匹配；LIKE 通配符按字面转义，参数化查询，每页 50 条。新查询丢弃旧响应，结果按链接去重；未完成缓存时明确提示仅覆盖已有部分，提供刷新结果和返回在线浏览。
- 输入 HTTPS 网址继续使用原有小说／章节解析流程，与书名搜索区分；没有新增夜社远程关键词搜索接口。本地书目不上传到设备同步或 APK。
